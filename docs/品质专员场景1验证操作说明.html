2查看KPI仪表板

  • 在线一次交验合格率(FPY) — 98.24%（目标≥99.0%）
  • 磁物检验异常率 — 10.0%（目标0%）
  • 异常料待处理 — 14批（目标0批）

3查看品质专员7个场景
观察：KPI下方应有7个场景卡片
预期：显示7个场景：
  1. 在线一次交验合格率管控（含🧠AI分析按钮）
  2. 磁物健康地图指标监控
  3. 异常料情况跟踪分析
  4. 库存呆滞情况跟踪分析
  5. 原料到货检验合格率管控(IQC)
  6. 制造过程磁物合格率监控(PMP)
  7. 全业务质量损失成本(COQ)分析
每个卡片底部有 🧠 AI分析 按钮
已完成
4查看场景1详情弹窗
操作：点击场景1卡片 在线一次交验合格率管控
预期：弹出详情弹窗，包含：
  • 七步分析流程 — 问题定义→现象分析→4M1E→根因→归因→CAPA→跟踪
  • 4M1E关联因素 — 人(操作技能/中)/机(设备精度/高)/料(正极材料/高)/法(工艺参数/中)
  • 关联指标 — FPY_RATE阈值97-99%
  • 当前告警 — FPY低于警戒线(W40批次异常)
  • 场景数据概览 — 近30日均FPY/样本数/产线数/异常产线
  • 数据预览 — 最新5条FPY记录（日期/产线/合格率/不良数）
说明：数据来自 ds_mock_data 表中场景1的90条模拟FPY数据。W40批次2#烧结线FPY出现断崖下跌至95%左右。
已完成
5🧠 AI分析（核心验证）
操作：在场景1卡片底部，点击 🧠 AI分析 按钮
等待：约3-8秒（OpenClaw调用deepseek-v4-flash模型推理）
预期：弹窗显示AI结构化分析报告，包含：
  • 品质状况评估 — 表格展示FPY/不良率/Cpk/不良集中度/设备状态
  • 异常指标识别 — 具体哪些指标不达标
  • 4M1E排查方向 — AI建议从人机料法环哪些维度排查
  • 下一步行动计划 — 可执行的行动项
技术背景：前端调用 POST /analysis/ai-run → 服务端通过 openclaw agent -m "prompt" --json 调用deepseek推理 → 结果返回前端渲染。全程不暴露Skill细节到前端。
已完成
6验证CAPA自动创建
操作：左侧导航点击 🔄 CAPA管理
预期：CAPA管理页面应看到：
  • 自动创建的CAPA方案 — 标题含"[AI自动] 在线一次交验合格率管控 异常告警分析"
  • 优先级：medium
  • 状态：open
  • 点击方案可查看详情、任务分解（含默认改善任务）
说明：AI分析返回内容中包含"异常""超标"等关键词时，自动触发CAPA创建。同时规则引擎评估FPY<97.5%命中阈值规则。
已完成
7系统配置 — 规则管理
操作：左侧导航点击 ⚙️ 系统配置 → 点击侧边栏 ⚙️ 规则管理
预期：场景1（FPY合格率管控）下有3条规则：
  • FPY阈值判定 — threshold（优先级1）✅ 启用
  • FPY连续下跌检测 — judgment_tree（优先级2）✅ 启用
  • FPY周趋势预警 — judgment_tree（优先级3）✅ 启用
每条规则可通过 ✏️ 编辑，修改阈值/优先级/启用状态
已完成
8系统配置 — 指标管理
操作：侧边栏点击 📊 指标管理
预期：7个指标列表，FPY_RATE排在第一个，阈值下限97%/上限100%，告警级别warning。每行最后有✏️编辑按钮，可修改阈值配置。
已完成
