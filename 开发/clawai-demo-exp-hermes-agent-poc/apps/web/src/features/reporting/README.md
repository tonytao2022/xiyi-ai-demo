# 统一报告渲染模式

## 原则

- 前端只消费 `StructuredReport`，不拼装业务结论。
- 前端按 `ReportBlock.type` 选择组件，不在组件内做指标口径推导。
- 所有导出能力都基于同一份报告 JSON，而不是重新计算页面数据。

## 组件分层

- 内容组件：`markdown`、结论说明、方法论说明、风险提示。
- 数据组件：`kpi_cards`、`table`、`chart`、分组对比卡。

## 渲染流程

1. 页面从 `BFF` 读取 `StructuredReport`。
2. 统一渲染器扫描 `sections` 与 `blocks`。
3. 渲染器根据 `type` 生成前端组件映射与展示参数。
4. 单个组件只关心展示，不更改报告中的数字、结论来源和数据血缘。

## 前端约束

- 不允许在前端写业务阈值、诊断规则和指标换算逻辑。
- 若区块缺失 `sourceRefs` 或关键字段，前端应进入降级展示而不是推断补齐。
- 任意核心数字旁都应可链接到 `sourceRefs` 或指标口径说明。
