# 1. Agent 与规则约定

## 1.1 目标

明确 `AGENTS.md` 与 `.cursor/rules/` 的职责边界，避免同类约定重复写在多个地方。

## 1.2 文件职责

### 1.2.1 `AGENTS.md`

- 面向项目级协作约定
- 说明项目定位、核心原则、模块职责、长期有效的工作方式
- 适合写“这个项目是什么、核心边界是什么、优先级是什么”

### 1.2.2 `.cursor/rules/*.mdc`

- 面向 Cursor 持久规则
- 适合写“遇到哪些文件时应该遵守什么约定”
- 可以做全局规则，也可以做按文件类型触发的规则

## 1.3 当前约定拆分

- `AGENTS.md`：承载项目级通用约定
- `00-项目总则.mdc`：承载始终适用的 AI 项目总则
- `01-TypeScript与服务约定.mdc`：承载 TypeScript、React、服务端实现约定
- `02-文档与架构约定.mdc`：承载文档分类和架构文档维护约定

## 1.4 使用建议

- 长期有效的项目原则优先写在 `AGENTS.md`
- 工具或编辑器需要自动感知的规则优先写在 `.cursor/rules/`
- 场景化、一次性的说明优先写在 `docs/architecture/`
