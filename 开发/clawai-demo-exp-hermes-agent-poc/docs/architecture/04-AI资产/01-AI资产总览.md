# 1. AI 资产总览

## 1.1 目标

沉淀本项目中与 AI 编排、模型使用、Prompt 管理、工具白名单和 Agent 约定相关的独立资产，避免这些关键信息散落在代码和聊天记录中。

## 1.2 当前资产

- `AGENTS.md`：项目级 Agent 约定
- `.cursor/rules/00-项目总则.mdc`：项目通用规则
- `.cursor/rules/01-TypeScript与服务约定.mdc`：TypeScript 与服务端/前端实现约定
- `.cursor/rules/02-文档与架构约定.mdc`：文档分类与架构维护约定

## 1.3 本目录文档

- `02-模型路由策略.md`：说明场景和步骤如何选择大模型
- `03-Prompt模板设计.md`：说明系统 Prompt、场景 Prompt 和模板变量
- `04-工具白名单设计.md`：说明 OpenClaw 可调用工具、边界和审计要求
- `05-Agent与规则约定.md`：说明 `AGENTS.md` 与 `.cursor/rules/` 的职责分工

## 1.4 使用方式

- 设计新场景时，先看模型路由、Prompt 和工具白名单是否需要调整。
- 新增长期有效的开发约定时，优先更新 `AGENTS.md` 或 `.cursor/rules/`。
- 新增一次性的设计决策时，优先更新 `docs/architecture/` 下的场景或实施计划文档。
